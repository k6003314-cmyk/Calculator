# Калькулятор для Windows

Проект использует C# и Windows Forms на .NET 10 LTS. Вычисления вынесены в `ExpressionEvaluator.cs`: парсер понимает скобки, приоритет операций, унарный знак, степень (`^`), квадратный корень (`√`), функции `sin` и `cos`, факториал, проценты и научную запись (`1.2e-3`). Он не выполняет введённый текст как код и не зависит от региональных настроек.

Это учебный проект.

## Документация пользователя

[Открыть документацию пользователя](https://docs.google.com/document/d/1g_XxtgeuGSu9CKfiIvYD6VPfRteI1H393UEfZxjxBPY/edit?tab=t.0)

Числа хранятся как `double`: диапазон примерно от `4.94e-324` до `1.7977e308` по модулю. Переполнение и округление ненулевого результата до нуля показываются как ошибки. Факториал поддерживается для целых чисел от `0` до `170`.

## Файлы проекта

- `Calculator.csproj` - настройки WinForms и целевая версия .NET.
- `Program.cs` - запуск приложения.
- `CalculatorForm.cs` - окно, кнопки и обработка клавиатуры.
- `ExpressionEvaluator.cs` - разбор и вычисление выражений.

## Запуск и сборка

Откройте PowerShell в папке `Calculator` и выполните:

```powershell
dotnet run --project .\Calculator.csproj
```

Сборка для 64-разрядной Windows без публикации:

```powershell
dotnet build .\Calculator.csproj -c Release -r win-x64
```

## Публикация

Автономная публикация в виде папки включает приложение и .NET Runtime. На целевом компьютере устанавливать .NET не нужно. Запустите из папки `Calculator`:

```powershell
dotnet publish .\Calculator.csproj -c Release -r win-x64 --self-contained true
```

Результат появится в `bin\Release\net10.0-windows\win-x64\publish\`. Для передачи скопируйте всю папку `publish`, а не один файл.

Чтобы получить один автономный EXE, используйте:

```powershell
dotnet publish .\Calculator.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:DebugType=None
```

В этом случае основной файл — `bin\Release\net10.0-windows\win-x64\publish\Calculator.exe`. Один файл проще передать; он заметно больше EXE из обычной сборки. Публикация `--self-contained true` без `PublishSingleFile` тоже не требует установленного .NET, но создаёт набор файлов, которые нужно передавать вместе.

Для разработки достаточно установить .NET 10 SDK. Автономный EXE рассчитан на 64-разрядные Windows 10/11. Для устройств ARM64 или 32-разрядных Windows требуется отдельная публикация под соответствующую платформу.

## Ручные проверки

В окне введите выражение и нажмите `=` или Enter:

- `2 + 2` → `4`.
- `2 + 3 * 4` → `14`.
- `(2 + 3) * 4` → `20`.
- `2^3` → `8`; `2^3^2` → `512` (степени вычисляются справа налево).
- `√9` → `3`; `√(2 + 7)` → `3`.
- `√-1` показывает сообщение об ошибке и не закрывает приложение.
- `5 / 2` → `2.5`.
- `10% + 10%` → `0.2`; `100 - 5%` → `95`.
- `1e308` принимается, `10^309` показывает ошибку переполнения, `1e-324` показывает ошибку слишком малого числа.
- После `1 ÷ 3 =` нажмите `× 3`: результат должен быть `1`.
- `5 / 0` → сообщение «На ноль делить нельзя.», приложение остаётся открытым.
- `2 + (` → понятное сообщение о некорректном выражении, приложение остаётся открытым.
- Проверьте цифры и `+`, `-`, `*`, `/`, Enter, Escape и Backspace на клавиатуре.
- Наберите `123`, нажмите `⌫` и убедитесь, что осталось `12`; нажмите `C` или Escape для очистки.
- Введите дробь как `1,5 + 1.0` — ответ должен быть `2.5`.
- Кнопка с булавкой в правом верхнем углу закрепляет окно поверх всех остальных; повторное нажатие отключает этот режим.
- После `=` результат становится текущим числом, а строка под ним сохраняет выражение, из которого он получился. Нажмите `+` и введите число, чтобы продолжить вычисление от результата; ввод цифры начинает новое выражение.

Автоматические проверки вычислительного класса не требуют сторонних библиотек. Из папки `Calculator` запустите:

```powershell
dotnet run --project .\Calculator.Checks\Calculator.Checks.csproj
```
